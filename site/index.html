Reef is an open agent harness built on OpenCode. It keeps the request prefix byte stable, sends two tool definitions instead of fifteen, and ends the loop on evidence rather than the model's word.

The harness sets the bill before the model answers.

Two harnesses on the same model, same task, can land 30% apart on tokens and 25% apart on wall clock. The difference is what they re-send, how many round trips a task takes, what the model sees at each step, and when the loop stops. That is the whole product.

Everything OpenCode already does well, Reef keeps. The loop and the request builder are what changed.

Four changes to the loop.

Reef is a delta, not a rewrite. Each layer ships with a measurement, in this order.

  1. 01

    Request discipline

    Requests only append. The prefix stays byte stable, tool discovery is appended rather than spliced in, and a monitor names the token that broke the cache.

  2. 02

    Script tool

    The model writes a program. The program calls Reef's tools through a bridge, inside a sandbox with no ambient authority. Many tool calls, one turn.

  3. 03

    Bounded loop

    Stop rules are deterministic: empty turns, identical calls, stream silence, retry limits, and token and wall clock budgets. No false stops on the control set.

  4. 04

    Anchoring

    Keep the prefix stable by default. Compact rarely, deliberately, and at a boundary, instead of on every turn.

If a claim cannot exit 0 or fail, it is a wish.

Progress is measured on a frozen rig against stock OpenCode: same model, same tasks, three runs per point. These are the bars the build has to clear.

0.1.0 installs from the tarball.

The npm package is a small launcher that links the native binary for your platform. No registry account, no credential, no service of ours in the path.

npm install -g ./reefcode-0.1.0.tgz ./reefcode-windows-x64-0.1.0.tgz
reef --version

Once 0.1.0 is on the registry, that becomes npm install -g reefcode.
